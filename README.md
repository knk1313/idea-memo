# IdeaMemo

日本語 | [English](README.en.md)

メニューバーに常駐するMac用のメモアプリ。メモは1件ずつMarkdownファイルとして保存されるので、ほかのエディターでも読み書きできる。

<img width="1668" height="946" alt="image" src="https://github.com/user-attachments/assets/30623fb9-f542-4bd5-8541-1bcc2616b883" />

## できること

- ⌃⌘Spaceで、どこからでも入力欄を開く
- 入力欄でMarkdownを書くと、その場で見た目に反映される
- メモを1件ずつMarkdownのファイルに保存し、作成日時などの情報を`index.json`にまとめる
- メモ一覧で、メモの検索、プレビュー、編集、削除をする
- 保存先のフォルダーを変え、既存のメモも一緒に移す

## 動かすのに必要な環境

- macOS 14以降
- Swift 5.9以降（Xcodeか、Command Line Toolsに含まれる）

外部のパッケージは使っていない。

## ビルドと起動

リポジトリのルートで次のコマンドを実行する。

```bash
./build.sh
open IdeaMemo.app
```

`build.sh`はリリースビルドをして、`IdeaMemo.app`を作る。起動すると、メニューバーに電球の形をしたIdeaMemoのアイコンが出る。Dockには出ない。

すでに起動しているアプリを作り直すときは、先に終了させる。

```bash
pkill -f IdeaMemo.app/Contents/MacOS/IdeaMemo
./build.sh
open IdeaMemo.app
```

ふだん使いにするときは、`--install`を付けて実行する。ビルドした`IdeaMemo.app`を`/Applications`に入れ替え、起動し直す。コードを直した後も、同じコマンドで入れ替えられる。

```bash
./build.sh --install
```

ログインしたときに自動で起動したいときは、システム設定の「一般」→「ログイン項目」に`/Applications/IdeaMemo.app`を足す。

## 使い方

### メモを書く

⌃⌘Spaceを押すと入力欄が開く。入力欄で使えるキーは次のとおり。

| キー | 動き |
| --- | --- |
| ⏎ | 保存して閉じる |
| ⌃⏎、⇧⏎ | 改行する |
| ⌘L | メモ一覧を開く |
| esc | 閉じる（書きかけの文は次に開いたときに残っている） |

日本語の変換中に押した⏎は、変換の確定として扱い、保存はしない。入力欄は行が増えると下に伸び、画面の高さいっぱいまで伸びると中をスクロールする。

### 入力欄でMarkdownを書く

入力欄とメモ一覧の編集画面では、書いた記法がその場で見た目に反映される。記号は消さずに薄く表示する。

- 見出し：`#`、`##`、`###`の後ろにスペースを一つ入れて始めた行は、文字が大きく太くなる
- 太字、斜体、取り消し線、コード、リンク：`**太字**`、`*斜体*`、`~~取り消し線~~`、`` `コード` ``、`[文言](URL)`と書くと、それぞれの見た目になる
- 箇条書き：`-`か`1.`の後ろにスペースを入れて始めた行で改行すると、次の行にも記号が入る。中身が空の行で改行すると、箇条書きが終わる
- チェックボックス：行頭で`[]`とスペースを打つと、`- [ ]`に変わる
- 字下げ：箇条書きの行でTabを押すと字下げし、⇧Tabで戻す

### メモ一覧で見る・直す・消す

メニューバーにあるIdeaMemoのアイコンから「メモ一覧」を選ぶか、⌘Lを押すとメモ一覧が開く。

- メモを選ぶと、Markdownのプレビューが出る。チェックボックスを押すと、ファイルの中身も`[x]`に変わる
- ⌘Eで、プレビューと編集を切り替える。編集した内容は自動で保存する
- 検索欄に語を入れると、本文にその語を含むメモだけが出る
- 各メモの選択ボタンを押して選び、「削除」を押すと、選んだメモをまとめて消す。Deleteキーでも消せる
- 消したメモのファイルはゴミ箱に移るので、Finderから戻せる

### 保存先を変える

メニューバーにあるIdeaMemoのアイコンから「保存先を変更…」を選び、フォルダーを選ぶ。メモ一覧の左下にある「変更…」からも選べる。

- 既存のメモは、すべて新しいフォルダーに移る。全件をコピーできてから元を消すので、途中で失敗しても元のメモは残る
- 移動先にすでにIdeaMemoのメモがあるときは、両方を合わせる
- 既定の保存先は`~/Documents/IdeaMemo`である

## 保存するファイル

保存先のフォルダーには、次の二つを置く。

```text
保存先/
├── index.json
└── notes/
    ├── 2026-11-06-194747.md
    └── 2026-11-06-201530.md
```

- `notes/`：メモの本文。1件を一つのMarkdownファイルにし、ファイル名は作成した日時にする
- `index.json`：メモごとのID、ファイル名、タイトル、作成日時、更新日時を記録する

ほかのエディターで`notes/`のファイルを直したり足したりしたときは、メモ一覧を開いたときに読み込み直す。

## 技術スタックとディレクトリ構成

SwiftとSwiftUIで書き、メニューバーとウィンドウの扱いにはAppKitを使う。どこからでも入力欄を開くキーは、Carbonの`RegisterEventHotKey`で登録する。この方法では、アクセシビリティの許可を求めない。

```text
.
├── Package.swift
├── build.sh                  # IdeaMemo.app を作る
└── Sources/IdeaMemo/
    ├── main.swift            # アプリの起動、メニューバー、メニュー、保存先の変更
    ├── HotKey.swift          # どこからでも入力欄を開くキーの登録
    ├── QuickPanel.swift      # 画面の中央に開く入力欄
    ├── MemoTextView.swift    # 入力欄の本体（改行、箇条書きの続き、字下げ）
    ├── MarkdownStyler.swift  # 入力中の文字にMarkdownの見た目を付ける
    ├── MarkdownView.swift    # メモ一覧のプレビュー
    ├── ListView.swift        # メモ一覧
    └── Store.swift           # メモの読み書き、保存先の移動
```
